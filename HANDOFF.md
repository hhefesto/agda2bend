## Record eta and the Yoneda lemma the Bend way, by hand (2026-10-30, 07:00-08:00)

The user (10-30): "there should be a way to model record eta that's natural for bend (and not the same way agda solves it)"; "I want the math to be sane. Bend should be able to do all that Agda can do, but in other ways. Find a sound way for Bend to demonstrate the same thing Agda proofs in bend's way of doing proofs."

- **What Bend does and does not do** (bend 2.0.39, probes in /tmp/bx/eta): function eta holds by `{==}` (`-f == x => f(x)`); constructor eta does not (`-p == P{P.a(p), P.b(p)}`: "expected p, observed P{..}"); an erased value cannot be matched outside a dead region ("a - scrutinee matches only in a dead region"); equality evidence is Data (`+e` is fine); a closure is affine, so a universally quantified hypothesis is usable once (even induction with a step hypothesis: "step consumed more than once"); the cases of one match do not add their uses.
- **hand/Eta.bend: records as functions of their field names** ("with" records). A projection is an application, so it computes on a variable record; eta is function eta; a record built from p's projections is p field by field (match on the field name); fields may share a resource (comp(g, f) uses g and f in both fields). Proves, over erased morphisms, the product-category laws agda-categories' Category.Product needs eta for: assoc, identities, pi_l/pi_r as functors, Swap an involution and a functor, uniqueness of pairing. Morphism equality pointwise, as agda-categories' (no function equality, so no eta needed in the kernel).
- **hand/YonedaSetoid.bend: agda-categories' Yoneda (yoneda-inverse), setoid-enriched**: for any category with hom-setoids, object A and setoid-valued presheaf F: from(x) is natural and respects equality, to and from respect equality, to . from = id, from . to = id on natural families; plus naturality in A and in F. The Bend way: natural transformations are raw families with naturality and respect as separate propositions (P-category style); a presheaf is flattened (carrier and equality families, laws uniform in an erased object), since a family of Setoid records needs the object live to reach a law; each proof matches each structure once and uses each law once (helpers SPsh.euclid, SCat.idlr). hand/YonedaSetoidExample.bend instantiates it (one object, Nat -> Nat in diagram order, Nat by application) and runs: 11.
- **--verdict:** all four hand files (Eta, YonedaSetoid, YonedaSetoidExample, Setoids) print ALL PROOFS CHECK from Bend's checker and the BendTT kernel. The box has Lean 4.34.0-rc2 only (bend wants 4.34.0; no elan binary), so the kernel was built with rc2 (/tmp/bx/bendtt/build.sh, then `BENDTT=/tmp/bx/bendtt/bendtt bend F.bend --verdict`). Kernel limits seen: two calls of the same def are compared by their arguments only (a law whose sides share a head goes through a common normal form, `via` in Eta.bend); a law between functions in a record field (a strict category of Nat -> Nat) fails the kernel after the checker eta-expands arguments, which bend reports as a checker/kernel mismatch, so the hand files state equalities pointwise.
- **Not done, for the translator:** emit non-dependent eta records as with-records; flatten families of records; natural transformations as raw families plus propositions; a proof that uses a structure twice matches it once in a helper. None of this is in Cata.bend yet.
